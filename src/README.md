# 随机抽选

在 ClassIsland 的「行动」里添加「随机抽选」，点一下就从名单里公平地抽一名同学，
屏幕中央弹出 ClassIsland 原生通知遮罩，显示 3 秒并朗读姓名。

## 使用

1. 名单在插件文件夹的 `名单.txt` 里，一行一个姓名（空行和 `#` 开头的行会被忽略）。
   第一次运行会生成示例文件。
2. 设置 → 自动化，新建行动组并添加「随机抽选」（在「点名」分组里），再配一个触发器。
3. 也可以在 **设置 → 随机抽选** 里直接编辑名单、查看已抽中、调整滑窗大小，不必打开文件夹。

## 抽选规则

- 候选池 = 全名单 − 已抽中；抽中即记录。
- 已抽中达到「滑窗大小」（默认 24）后，每抽一次淘汰最早抽中的那位。
  39 人班、滑窗 24 → 候选池恒为 15 人，被抽中的人在接下来 23 次抽选内不会再出现。
- 没有「重开一轮」逻辑，记录不会被清空；随机数取自操作系统熵源。

## 数据

`抽选数据.json`：

```json
{
  "allNames": ["张三", "李四", "王五"],
  "pickedNames": ["李四"],
  "maxPickedCount": 24
}
```

`allNames` 为空时才从 `名单.txt` 读取并回写；`pickedNames` 按抽取先后记录。

## 语音

朗读用 ClassIsland 自带的 TTS（设置 → 提醒 → 语音）。提醒音效已关闭，避免和朗读叠声。
